# @forgeron/manifest

The manifest of a Forgeron tool: its schema (Zod), and the comparison of two versions, which tells the impact of a change and what an admin approves. Used by the SDK, the runtime and the CLI. Documentation: [docs/sdk.md](https://github.com/forgeron-sh/monorepo/blob/main/docs/sdk.md).

## In the monorepo

Depends on no other package in the repository (`manifest-is-a-leaf` rule).
